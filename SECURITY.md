## Reporting a Vulnerability

We take the security of My Wardrobe seriously. If you discover a vulnerability or potential security risk, please report it privately rather than opening a public issue.

### How to Report

1. **GitHub Private Security Advisory**: Go to the **Security** tab of this repository and select **Report a vulnerability**.
2. **Direct Contact**: If GitHub Advisories are not accessible, contact the maintainer directly via GitHub profile details.

Please include in your report:
- A description of the issue and potential impact
- Step-by-step reproduction instructions or proof-of-concept
- Any suggestions for mitigation or remediation

### Response Timeline
- **Acknowledgement**: Within 48 hours.
- **Assessment & Fix**: Typically within 7 business days depending on severity.
- **Disclosure**: Coordinated public disclosure after a fix has been released.
